Resumo
A Mentis – Psicologia Inovada é uma plataforma web desenvolvida como projeto acadêmico de Trabalho de Conclusão de Curso, com foco em bem-estar emocional e saúde mental no contexto pessoal e organizacional. A proposta é oferecer uma ferramenta acessível para que usuários realizem avaliações comportamentais e acompanhem seus resultados, sem transformar o resultado em diagnóstico ou laudo médico.
O sistema possui dois ambientes principais: Funcionário e Empresa/RH. O funcionário realiza o cadastro, acessa o questionário, acompanha o status de seus testes e visualiza seus próprios resultados. A conta Empresa/RH possui um painel administrativo em estilo SaaS, com funcionários vinculados e indicadores baseados nos dados disponíveis no sistema. O backend é desenvolvido em Python com Flask, com banco de dados PostgreSQL/Supabase e interface construída com HTML, CSS e JavaScript.
A documentação apresenta a visão de negócio, objetivos, metodologia, requisitos funcionais e não funcionais, regras de negócio, arquitetura, principais fluxos, estrutura do banco, segurança, acessibilidade, organização do projeto e pendências conhecidas.
Palavras-chave
Flask. Python. Saúde mental. Bem-estar emocional. Sistema web. PostgreSQL. Supabase. RH. Segurança. Acessibilidade.

Abstract
Mentis – Psicologia Inovada is a web platform developed as an academic Final Course Project focused on emotional well-being and mental health in personal and organizational contexts. The platform provides behavioral assessments and result tracking without treating its results as medical diagnosis or professional reports.
The system has two main environments: Employee and Company/HR. Employees can register, take assessments, follow the status of their tests and view their own results. Company/HR accounts have a SaaS-style administrative dashboard with linked employees and indicators based on the available system data. The backend uses Python and Flask, with PostgreSQL/Supabase as the database and HTML, CSS and JavaScript for the interface.
