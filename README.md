# Mentis – Psicologia Inovada

## Resumo

A **Mentis – Psicologia Inovada** é uma plataforma web desenvolvida como projeto acadêmico de Trabalho de Conclusão de Curso (TCC), com foco em bem-estar emocional e saúde mental nos contextos pessoal e organizacional.

A proposta é oferecer uma ferramenta acessível para que os usuários realizem avaliações comportamentais e acompanhem seus resultados, sem transformar as informações obtidas em diagnóstico ou laudo médico.

O sistema possui dois ambientes principais:

- **Funcionário:** realiza o cadastro, acessa o questionário, acompanha o status dos seus testes e visualiza seus próprios resultados.
- **Empresa/RH:** possui um painel administrativo em estilo SaaS, com funcionários vinculados e indicadores baseados nos dados disponíveis no sistema.

### Tecnologias

O backend da aplicação é desenvolvido utilizando **Python e Flask**, com **PostgreSQL/Supabase** como banco de dados. A interface é construída com **HTML, CSS e JavaScript**.

A documentação do projeto apresenta a visão de negócio, objetivos, metodologia, requisitos funcionais e não funcionais, regras de negócio, arquitetura, principais fluxos, estrutura do banco de dados, segurança, acessibilidade, organização do projeto e pendências conhecidas.

## Abstract

**Mentis – Psicologia Inovada** is a web platform developed as an academic Final Course Project focused on emotional well-being and mental health in personal and organizational contexts.

The platform provides behavioral assessments and result tracking without treating the results as medical diagnoses or professional reports.

The system has two main environments:

- **Employee:** users can register, take assessments, follow the status of their tests and view their own results.
- **Company/HR:** accounts have a SaaS-style administrative dashboard with linked employees and indicators based on the data available in the system.

The backend is developed using **Python and Flask**, with **PostgreSQL/Supabase** as the database and **HTML, CSS and JavaScript** for the interface.
