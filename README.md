# 1. Apresentação do projeto
O Mentis – Psicologia Inovada é um projeto desenvolvido como parte do curso Técnico em Desenvolvimento de Sistemas.
A proposta surgiu com o objetivo de desenvolver uma plataforma digital voltada para o acompanhamento do bem-estar emocional das pessoas, utilizando tecnologia para facilitar uma primeira reflexão sobre diferentes aspectos relacionados ao ambiente de trabalho e à vida profissional.
O projeto não tem como objetivo realizar diagnósticos médicos ou psicológicos. A plataforma apresenta indicadores e perfis baseados nas respostas fornecidas pelo usuário, servindo como uma ferramenta de orientação e conscientização.
A ideia principal é utilizar a tecnologia como uma forma de incentivar o cuidado com a saúde emocional e facilitar a identificação de possíveis situações que mereçam maior atenção.

# 2. Objetivo do Mentis
O principal objetivo do Mentis é criar uma plataforma simples e acessível para que uma pessoa possa responder a um questionário relacionado ao seu bem-estar emocional.
A partir das respostas, o sistema organiza os dados e apresenta indicadores que ajudam o usuário a compreender como determinados aspectos aparecem em seu resultado.
Entre os aspectos trabalhados pelo projeto estão:
Ansiedade;
Foco e Atenção;
Sobrecarga Mental;
Relacionamentos e Comunicação;
Equilíbrio Emocional;
Aspectos relacionados ao ambiente de trabalho.
Os resultados são apresentados como indicadores e classificações, e não como diagnósticos.
O sistema também foi pensado considerando situações relacionadas ao ambiente corporativo e à discussão sobre saúde mental no trabalho.
